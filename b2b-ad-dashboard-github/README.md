# B2B 광고 데이터 대시보드

React, Vite, Tailwind CSS, Recharts 기반의 배포용 프로젝트입니다.

## 실행

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
```

Vercel에서는 GitHub Repository를 연결한 뒤 Framework `Vite`, Build Command `npm run build`, Output Directory `dist`로 배포합니다.

`node_modules`, `dist`, `.vite`는 GitHub에 올리지 않습니다. 필요한 패키지는 `npm install`로 복원됩니다.
